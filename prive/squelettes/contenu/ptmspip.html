PTM inventorie désormais l’environnement SPIP puis analyse le HTML public rendu. Il distingue intégration potentielle, collecte de données, service externe et preuve technique réellement observée.

#FORMULAIRE_PTM_SPIP_SCAN

Ce que cette version sait faire

  • inventorier tous les plugins SPIP actifs et reconnaître les profils RGPD connus ;
  • laisser visibles les plugins inconnus et signaler ceux dont le nom suggère une fonction liée aux données ;
  • recenser accueil, articles publiés, rubriques publiées et page mentions ;
  • traiter 5 pages maximum par requête ;
  • repérer 32 familles de services/traceurs externes connues ;
  • signaler les domaines tiers inconnus réellement chargés ;
  • repérer les formulaires rendus susceptibles de collecter e-mail, téléphone, identité, adresse, message, mot de passe ou fichier ;
  • signaler un formulaire qui envoie directement vers un autre domaine ;
  • ne jamais classer un simple lien sortant comme traceur.

Limite volontaire : aucun mécanisme de blocage/consentement n’est encore activé. La présence d’un plugin est une indication, jamais une preuve de traceur.
