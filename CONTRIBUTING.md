# Contributing

Contributions are welcome for tracker detection, SPIP integration, accessibility, documentation and tests.

Please keep changes compatible with PTM's shared rules and privacy goals:

- never commit production configuration, credentials or personal data;
- document evidence for new tracker rules;
- keep detection deterministic and explainable;
- preserve compatibility with supported SPIP versions;
- run available checks before proposing a change.

Report vulnerabilities privately using `SECURITY.md`.

Contributions are provided under GPL-2.0-or-later.
